# An-lisis-de-ventas-de-cursos-por-pais
Proyecto personal en Power BI para analizar la venta de cursos online.  ¿Qué muestra el dashboard? - TOTAL FACTURADO y TICKET PROMEDIO en tiempo real - Top Países por Demanda: mapa interactivo con heatmap - Cursos Más Vendidos: Excel, Access, Word lideran - Horarios con más demanda: Mañana, Tarde y Noche - Ciudades con mayor concentración de ventas
