Análisis de Ventas de Cursos por País - Power BI

Dashboard interactivo desarrollado en Power BI para analizar el rendimiento de ventas de cursos online por país, curso y horario.

Objetivo del Proyecto
Simular un caso real de negocio para practicar:
- Limpieza y modelado de datos
- Creación de KPIs con DAX
- Visualización y storytelling de datos
- Diseño de dashboards para ejecutivos

KPIs Principales
- TOTAL FACTURADO: Suma total de ventas
- TICKET PROMEDIO: Promedio de importe por cliente

Visualizaciones Incluidas
1.  Mapa de Calor: Top Países por Demanda de Cursos con filtro RANGO PAIS
2.  Gráfico de Torta: Cursos Más Vendidos (Excel es el #1 con 26.85%)
3.  Mapa: Horarios de Curso con Más Demanda (Mañana, Tarde, Noche)
4.  Mapa: Ciudades donde más cursos se compraron

Herramientas Utilizadas
- Power BI Desktop
- DAX para medidas: "TOTAL FACTURADo", "TICKET PROMEDIO"
- Datos simulados de ventas de cursos
